# מסלולי למידה – לתלמידים עם קשיי קשב

מערכת למורות לבניית מסלולי למידה עצמאיים. המורה נרשמת, בונה מסלול, מוסיפה משימות, מעצבת אותו ומשתפת קוד עם התלמידים.
התלמידים מתקדמים משימה אחר משימה על "מפה", והמורה רואה את ההתקדמות שלהם בזמן אמת.

## הפעלה

דרוש Node.js בגרסה 22.13 ומעלה (משתמש ב-SQLite המובנה ב-Node). התלות היחידה היא ה-SDK של Anthropic, למחולל המסלולים.

```bash
cd learning-paths
npm install
npm start          # http://localhost:3000
npm test           # בדיקות
```

משתני סביבה:
- `PORT` (ברירת מחדל 3000), `DB_FILE` (ברירת מחדל `data/app.db`), `COOKIE_SECURE=1` כשמריצים מאחורי HTTPS.
- `ANTHROPIC_API_KEY` – מפעיל את מחולל המסלולים. בלי מפתח כל השאר עובד, והמחולל מציג הודעה שהוא לא מוגדר. מפתח יוצרים ב-[console.anthropic.com](https://console.anthropic.com).

## גרסת הדגמה (בלי שרת)

התיקייה `demo/` בונה גרסה שרצה כולה בדפדפן, כ-Artifact ב-claude.ai: אותו ממשק, כשה-API נענה בתוך הדף (`demo/demo-api.js`) במקום ב-`server.js`. הבדיקה, ההסתרה של התשובות והטיפול בפלט המחולל מגיעים מאותם מודולים (`logic.js`, `validate.js`, `ai-prompt.js`). הנתונים נשמרים במסד הנתונים הפרטי של הצופה ב-Artifact, והמחולל משתמש בחשבון Claude של הצופה. PDF לא נתמך בהדגמה.

```bash
node demo/build.mjs   # יוצר את demo/dist
```

## העלאה לאינטרנט (Render)

בשורש הריפו יש קובץ `render.yaml` שמגדיר הכול: שרת Node, דיסק קבוע למסד הנתונים ובדיקת תקינות.

1. נרשמים ל-[render.com](https://render.com) עם חשבון ה-GitHub.
2. **New → Blueprint**, בוחרים את הריפו ולוחצים **Apply**.
3. Render יבקש את הערך של `ANTHROPIC_API_KEY` (בשביל מחולל המסלולים). אפשר להשאיר ריק ולהוסיף אחר כך בלשונית Environment.
4. אחרי כמה דקות המערכת זמינה בכתובת `https://learning-paths.onrender.com` (או דומה). דומיין משלך מחברים ב-Settings → Custom Domains.

הערות:
- הדיסק דורש חבילה בתשלום (Starter). בחבילה החינמית כל הנתונים נמחקים בכל הפעלה מחדש.
- גיבוי: מומלץ להפעיל snapshots לדיסק בהגדרות של Render.
- Render קורא את `render.yaml` מהענף שבוחרים בהגדרות השירות.

## מה יש למורה

- **הרשמה וכניסה** – סיסמאות מוצפנות (scrypt), עוגיית סשן HttpOnly.
- **המסלולים שלי** – יצירת מסלול ריק או ממסלול לדוגמה, שכפול ומחיקה.
- **משימות** – קריאה/הסבר (עם תמונה), סרטון/קישור (יוטיוב מוטמע), שאלה פתוחה, שאלה אמריקאית, רשימת צעדים וזמן עבודה מרוכז עם שעון. לכל משימה זמן משוער וסמל. שינוי סדר בגרירה או בחצים.
- **משחקים ותרגול** – משחק זיכרון (זוגות של מילה/אימוג׳י/תרגיל), תפזורת (טבלה נבנית אוטומטית), התאמה, סידור לפי הסדר, השלמת מילים עם מחסן מילים ומסיחים, ונכון/לא נכון. התשובות נבדקות בשרת ולא נשלחות לדפדפן של התלמיד; תשובה שגויה מסמנת בדיוק מה לתקן.
- **ניקוד** – מקלדת ניקוד בכל שדה טקסט בעורך (כל התנועות, דגש, שי״ן/שׂי״ן, חולם מלא, שורוק, והסרת ניקוד), וכפתור שמעתיק את הטקסט ופותח את המנקד האוטומטי של דיקטה. בבדיקת תשובות הניקוד לא משנה.
- **מחולל מסלולים (AI)** – כותבים נושא, בוחרים שכבת גיל, מטרות, מספר משימות וסוגי משימות, אפשר לבקש ניקוד מלא ולצרף חומרים (PDF, ‏Word, תמונות, טקסט). המחולל (Claude) בונה מסלול שלם לפי עקרונות של למידה לתלמידי קשב, והוא נשמר כטיוטה לעריכה. כל משימה שחוזרת מהמחולל עוברת את אותה בדיקה כמו משימה שהמורה כתבה.
- **עיצוב** – 8 ערכות מוכנות בלחיצה (קלאסי, חלל, מתחת לים, יער, ממתקים, מחברת, שקיעה, לילה רגוע), ומעבר להן: 12 צבעים ועוד צבע חופשי, מצב יום/לילה, 9 רקעים, 32 סמלים, 5 פונטים, 3 צורות מסלול (דרך מתפתלת, כרטיסים, קו ישר), צורת תחנות (עיגול, ריבוע רך, משושה), סגנון כרטיסים (רך, מסגרת עבה, זכוכית), דמות מלווה שמעודדת את התלמיד/ה, ו-5 סוגי חגיגה. תצוגה חיה ושמירה אוטומטית.
- **אישור מורה** – אפשר לסמן משימה כ"עצירה לאישור המורה". בסוף המשימה התלמיד/ה ממתין/ה, והמורה מקלידה על המסך שלו/ה את קוד האישור של המסלול (4 ספרות, מוסתר במסך המורה עד שמבקשים להציג): "אישור והמשך" או "צריך לתקן". אפשר לאשר גם מרחוק מטבלת ההתקדמות. הקוד לא נשלח לתלמידים, ואחרי 8 ניסיונות שגויים ב-10 דקות הניסיונות נחסמים.
- **התקדמות והפסקות** – פתיחת משימה רק אחרי סיום הקודמת (או חופשי), הפסקת תנועה כל X משימות, חגיגה בסיום משימה, כפתור הקראה בקול.
- **שיתוף** – קוד בן 6 תווים, קישור ישיר וכרטיס להדפסה. המסלול גלוי לתלמידים רק אחרי "פרסום".
- **התקדמות** – טבלת תלמידים × משימות, צפייה בתשובות, בקשות עזרה ("טופל"), רענון אוטומטי.
- **תצוגה מקדימה** – המורה רואה בדיוק את מסך התלמיד, בלי לשמור התקדמות.

## קרדיטים ומנוי

- כל מורה מקבלת **20 קרדיטים חינם** בהרשמה.
- **מסלול חדש** (בנייה עצמאית, ממסלול לדוגמה או שכפול) עולה **קרדיט אחד**. **מסלול מהמחולל** עולה **5 קרדיטים**. עריכה של מסלולים קיימים, תלמידים ומעקב נשארים חינם.
- **מנוי חודשי**: 200 קרדיטים שמתחדשים כל חודש. קרדיטי המנוי נצרכים ראשונים ופגים בסוף החודש. הקרדיטים החינמיים (וקרדיטים שנוספו ידנית) לא פגים.
- אם יצירת מסלול במחולל נכשלת, הקרדיטים חוזרים אוטומטית. בעמוד "הקרדיטים שלי" יש יתרה, מחירון, מצב המנוי והיסטוריית שימוש.

כל המספרים נקבעים במשתני סביבה: `FREE_CREDITS`, `MONTHLY_CREDITS`, `COST_CREATE_PATH`, `COST_AI_GENERATE`, `PRICE_LABEL` (הטקסט שמוצג כמחיר, ברירת מחדל "₪39 לחודש").

**תשלום:** עוד לא מחוברת חברת סליקה.
- `PAYMENTS_MODE=test` – כפתור "הצטרפות למנוי" מפעיל מנוי בלי חיוב, לבדיקה.
- בלי ההגדרה – הכפתור מוחלף בהודעה שהתשלום המקוון עוד לא הופעל.
- בינתיים אפשר לנהל מורות ידנית (למשל בית ספר שמשלם בחשבונית):

```bash
npm run admin -- show dana@school.org
npm run admin -- grant dana@school.org 50        # קרדיטים קבועים
npm run admin -- subscribe dana@school.org 12    # מנוי ל-12 חודשים (עם הקרדיטים של כל החודשים)
npm run admin -- cancel dana@school.org
```

## מה יש לתלמיד

- נכנסים עם קוד + שם (בלי סיסמה). חזרה עם אותו שם ממשיכה מאותה נקודה.
- מפה עם תחנות, "את/ה כאן!", פס התקדמות וכוכבים.
- משימה אחת על המסך, גדולה וברורה, עם זמן משוער, הקראה וכפתור "צריך/ה עזרה".
- חגיגה וכוכב על כל משימה, הפסקות תנועה עם טיימר, מסך סיום עם גביע.
- מכבד את הגדרת "הפחתת תנועה" של המכשיר.

## מבנה

```
server.js      שרת HTTP + כל ה-API
db.js          סכמת SQLite
validate.js    בדיקת קלט (משימות, עיצוב, משתמשים)
templates.js   מסלול לדוגמה
ai.js          מחולל המסלולים: פרומפט, סכמת JSON, קבצים, קריאה ל-Claude
docx.js        חילוץ טקסט מקובצי Word
billing.js     כללי הקרדיטים והמנוי (משותף לשרת ולהדגמה)
logic.js       בדיקת תשובות ועיבוד פלט המחולל (משותף לשרת ולהדגמה)
admin.js       ניהול קרדיטים ומנויים מהשורה
public/        ממשק (HTML/CSS/JS ללא build)
  js/teacher.js   מסכי המורה
  js/student.js   מסכי התלמיד
  js/games.js     משחקי התלמיד
  js/nikud.js     מקלדת הניקוד
  js/generator.js מסך מחולל המסלולים
test/          בדיקות API (node:test)
```

## הערות

- כניסת תלמיד לפי שם בלבד: מי שיודע את הקוד ואת השם יכול להמשיך את המסלול של אותו תלמיד. זה מתאים לכיתה, אבל לא לשמירת מידע רגיש.
- המחולל שולח את הנושא והקבצים ל-Anthropic. אין לצרף מידע אישי על תלמידים. כל יצירת מסלול עולה כמה סנטים עד עשרות סנטים בחשבון ה-API, לפי אורך הקבצים. יש מגבלה של 20 מסלולים לשעה למורה.
- הפונטים נטענים מ-Google Fonts (Rubik, Varela Round, Playpen Sans Hebrew, Secular One). בלי אינטרנט המערכת עובדת עם פונט המערכת.
