# 3, 2, 1… שיגור! – מדריך הקמה למורה

המשחק עובד מיד מול בולי ובאותו טלפון, גם בלי שום הגדרה.
כדי שילדים ישחקו **עם חברים מהטלפונים שלהם**, צריך להקים פעם אחת "מחסן נתונים" חינמי של גוגל (Firebase). זה לוקח בערך 15 דקות.

**מה יש בתיקייה:**
- `site/` – זו התיקייה שמעלים לאינטרנט. בתוכה `index.html` ותיקיית `images/` עם כל האיורים.
- `database.rules.json` – חוקי האבטחה (מדביקים אותם בשלב 4).
- המדריך הזה.

---

## שלב 1 – יוצרים פרויקט ב-Firebase
1. נכנסים ל-**console.firebase.google.com** עם חשבון גוגל.
2. לוחצים **"יצירת פרויקט"** (Create a project).
3. נותנים שם, למשל `shigur-class`, וממשיכים.
4. כשמציעים Google Analytics – אפשר לכבות. לוחצים **"יצירת פרויקט"** ומחכים שיסתיים.

## שלב 2 – מפעילים כניסה אנונימית
הילדים לא נרשמים ולא מקלידים מייל. המערכת רק נותנת לכל טלפון "מספר סודי" אקראי.
1. בתפריט מימין/משמאל: **Build ← Authentication** ← **"Get started"**.
2. לשונית **Sign-in method** ← בוחרים **Anonymous** ← מדליקים **Enable** ← **Save**.

## שלב 3 – יוצרים את מחסן הנתונים
1. בתפריט: **Build ← Realtime Database** ← **"Create Database"**.
2. בוחרים מיקום (למשל **Belgium (europe-west1)**) ← **Next**.
3. בוחרים **"Start in locked mode"** ← **Enable**.
4. למעלה מופיעה כתובת שמתחילה ב-`https://` ונגמרת ב-`firebasedatabase.app` או `firebaseio.com`. שימו לב אליה – נצטרך אותה בשלב 5.

## שלב 4 – מדביקים את חוקי האבטחה
החוקים דואגים ש: רק מי שנכנס למשחק יכול לקרוא, כל ילד כותב רק את עצמו, ורק מי שבחדר יכול לשחק בו.
1. ב-Realtime Database עוברים ללשונית **Rules**.
2. מוחקים את כל מה שכתוב שם.
3. פותחים את הקובץ `database.rules.json`, מעתיקים את **כל** התוכן ומדביקים.
4. לוחצים **Publish**.

## שלב 5 – מעתיקים את ההגדרות לקובץ המשחק
1. לוחצים על גלגל השיניים ⚙️ ליד "Project Overview" ← **Project settings**.
2. גוללים למטה ל-**"Your apps"** ← לוחצים על הסמל **`</>`** (Web).
3. נותנים כינוי (למשל `shigur`) ← **Register app**. (לא צריך לסמן Hosting.)
4. מופיע קטע קוד עם `firebaseConfig`. מעתיקים ממנו חמישה ערכים: `apiKey`, `authDomain`, `databaseURL`, `projectId`, `appId`.
   - אם אין שם `databaseURL` – מעתיקים את הכתובת משלב 3, סעיף 4.
5. פותחים את `site/index.html` בעורך טקסט פשוט:
   - ב-Windows: קליק ימני ← "פתח באמצעות" ← **פנקס רשימות** (Notepad).
   - במק: **TextEdit**, ולפני כן בתפריט Format לבחור **Make Plain Text**.
6. ממש בראש הקובץ יש בלוק שמתחיל ב-`const CONFIG`. ממלאים בין המירכאות:

```js
const CONFIG = {
  firebase: { apiKey:"AIza...", authDomain:"shigur-class.firebaseapp.com", databaseURL:"https://shigur-class-default-rtdb.europe-west1.firebasedatabase.app", projectId:"shigur-class", appId:"1:123...:web:abc..." },
  classCode: "tavenkin-b2",
  studentNames: ["נועה", "איתי", "מאיה", "יואב"]
};
```

- **classCode** – קוד כיתה שאתן בוחרות, באנגלית, ספרות ומקף, בלי רווחים. רק ילדים עם אותו קוד רואים זה את זה. אם יש שתי כיתות – לכל אחת קובץ עם קוד אחר.
- **studentNames** – שמות פרטיים בלבד, כל שם בתוך מירכאות, עם פסיק ביניהם. הילדים יבחרו את השם שלהם מכפתורים. אם משאירים `[]` ריק – כל ילד כותב שם פרטי בעצמו.
- שומרים את הקובץ (שימו לב שהשם נשאר `index.html`, ולא `index.html.txt`).

> לא לגעת בשום דבר אחר בקובץ. אם משהו השתבש – פשוט מתחילים שוב מהקובץ המקורי.

## שלב 6 – מעלים לאינטרנט (Netlify)
1. נכנסים ל-**app.netlify.com/drop** (אפשר להירשם בחינם עם חשבון גוגל).
2. **גוררים את התיקייה `site`** כולה (זו שבתוכה `index.html` ו-`images`) אל המסגרת באתר.
3. אחרי כמה שניות מקבלים כתובת, למשל `https://joyful-rocket-12345.netlify.app`. זו הכתובת של המשחק.
4. (רשות) אפשר לשנות את השם: **Site configuration ← Change site name**, למשל `shigur-tavenkin`.

**עדכון בהמשך** (למשל הוספת שם תלמיד): עורכים את `index.html`, ואז ב-Netlify נכנסים לאתר ← לשונית **Deploys** ← גוררים שוב את התיקייה `site`.

## שלב 7 – מאשרים ל-Firebase את כתובת האתר
1. ב-Firebase: **Authentication ← Settings ← Authorized domains**.
2. **Add domain** ← מדביקים את הכתובת מ-Netlify **בלי** `https://` (למשל `shigur-tavenkin.netlify.app`) ← **Add**.
3. אם שיניתם את שם האתר ב-Netlify – להוסיף גם את השם החדש.

## איך בודקים לבד
1. פותחים את כתובת האתר בשני מכשירים: שני טלפונים, או טלפון ומחשב.
   (במחשב אפשר גם חלון רגיל + חלון גלישה בסתר – כל אחד נחשב "ילד" אחר.)
2. בכל מכשיר לוחצים **שַׂחֲקוּ** ובוחרים שם וטיל (שמות שונים, כדי שיהיה קל לזהות).
3. במכשיר הראשון: **מְשַׂחֲקִים עִם חֲבֵרִים**. המכשיר השני יכול להישאר במסך הבחירה.
4. אחרי כמה שניות מופיע כרטיס של החבר. בוחרים שלב, לוחצים על הכרטיס ואז **מַזְמִינִים!**
5. במכשיר השני קופץ חלון הזמנה עם צליל ← **בּוֹא/י נְשַׂחֵק!**
6. במכשיר הראשון מופיעים שני הטילים ← **מַתְחִילִים!**
7. משחקים: מי שבתור – מטיל, עונה "צריך המרה?", גורר בלוק, מוציא קוביות וכותב. המכשיר השני רואה הכל בזמן אמת, ובסוף התור בודק "צדק / טעה" ויכול לשלוח תגובה 👏.
8. בדיקת ניתוק: סוגרים את הדפדפן במכשיר אחד. אחרי כ-45 שניות במכשיר השני מופיע "{שם} התנתק" עם "מחכים" / "בולי ממשיך במקומו". פותחים שוב את האתר במכשיר שנסגר – הוא חוזר לאותו משחק.
9. דרך נוספת: **חֶדֶר עִם קוֹד** ← **יוֹצְרִים חֶדֶר** ← מקבלים קוד של 4 תווים. במכשיר השני מקישים את הקוד ← **נִכְנָסִים**. או לוחצים **שׁוֹלְחִים קִשּׁוּר** ושולחים את הקישור להורים בוואטסאפ – הקישור מכניס ישר לחדר.

## אם משהו לא עובד
- **"המשחק עם חברים עוד לא מוכן"** – בלוק ה-`firebase` בקובץ ריק או חסר בו `apiKey` / `databaseURL`. חוזרים לשלב 5.
- **"משהו לא עבד"** כשנכנסים לחברים – בדקו את שלב 2 (Anonymous מופעל) ואת שלב 7 (כתובת Netlify ברשימה).
- **לא רואים את החבר** – ודאו ששני המכשירים פתחו את **אותה כתובת**, ושבקובץ יש אותו `classCode`.
- **חסרים איורים** – ודאו שהעליתם את כל התיקייה `site` (כולל `images`), ולא רק את `index.html`.

## פרטיות ובטיחות
- נשמרים רק שם פרטי וצבע טיל. אין מייל, אין סיסמה, אין צ'אט – רק תגובות קבועות (👏 🚀 ⭐ 😄, "כל הכבוד!", "יופי של תור!", "בהצלחה!").
- רואים ומזמינים רק ילדים מאותה כיתה (אותו `classCode`). אין לובי ציבורי.
- חדר נמחק כשכולם יוצאים ממנו, וחדרים בני יותר מ-24 שעות נמחקים אוטומטית.
- התוכנית החינמית של Firebase (Spark) מספיקה בהרבה לכיתה.
