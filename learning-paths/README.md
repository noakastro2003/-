# מסלולי למידה – לתלמידים עם קשיי קשב

מערכת למורות לבניית מסלולי למידה עצמאיים. המורה נרשמת, בונה מסלול, מוסיפה משימות, מעצבת אותו ומשתפת קוד עם התלמידים.
התלמידים מתקדמים משימה אחר משימה על "מפה", והמורה רואה את ההתקדמות שלהם בזמן אמת.

## הפעלה

דרוש Node.js בגרסה 22.13 ומעלה. מסד הנתונים הוא Postgres: באתר החי Netlify Database, ובמחשב מקומי ובבדיקות PGlite (Postgres שרץ בתוך Node, בלי התקנה). הסכמה נמצאת ב-`netlify/database/migrations/`.

```bash
cd learning-paths
npm install
npm start          # http://localhost:3000
npm test           # בדיקות
```

משתני סביבה:
- `PORT` (ברירת מחדל 3000), `DB_FILE` – תיקיית מסד הנתונים המקומי (ברירת מחדל `data/pg`), או `DATABASE_URL` לשרת Postgres. `COOKIE_SECURE=1` כשמריצים מאחורי HTTPS.
- `ADMIN_EMAILS` – כתובות האימייל (מופרדות בפסיקים) של מנהלי האתר. הם רואים כפתור "🛠️ ניהול" ויוצרים שם קודי הטבה.
- `PAYMENTS_MODE=test` – כפתור ההצטרפות למנוי מפעיל מנוי בלי חיוב (לבדיקות). בלי הגדרה התשלום המקוון כבוי.
- `APP_URL` – הכתובת הציבורית של האתר (לקישורי איפוס סיסמה באימייל).
- `RESEND_API_KEY` ו-`MAIL_FROM` – שליחת אימיילים דרך Resend. בלי הגדרה, קישורי האיפוס נכתבים ליומן השרת.
- `DICTA_ENABLED=0` מכבה את הניקוד של דיקטה; `DICTA_URL` משנה את כתובת השירות.
- `ANTHROPIC_API_KEY` – מפעיל את מחולל המסלולים. בלי מפתח כל השאר עובד, והמחולל מציג הודעה שהוא לא מוגדר. מפתח יוצרים ב-[console.anthropic.com](https://console.anthropic.com).

## גרסת הדגמה (בלי שרת)

התיקייה `demo/` בונה גרסה שרצה כולה בדפדפן, כ-Artifact ב-claude.ai: אותו ממשק, כשה-API נענה בתוך הדף (`demo/demo-api.js`) במקום ב-`server.js`. הבדיקה, ההסתרה של התשובות והטיפול בפלט המחולל מגיעים מאותם מודולים (`logic.js`, `validate.js`, `ai-prompt.js`). הנתונים נשמרים במסד הנתונים הפרטי של הצופה ב-Artifact, והמחולל משתמש בחשבון Claude של הצופה. PDF לא נתמך בהדגמה.

```bash
node demo/build.mjs   # יוצר את demo/dist
```

## האתר החי (Netlify)

האתר רץ ב-Netlify: הדפים מהתיקייה `public/`, וכל `/api/*` עובר לפונקציה `netlify/functions/api.mjs`, שמריצה את אותו קוד של `server.js`.
- **מסד נתונים:** Netlify Database. בכל פריסה Netlify מריץ את קבצי ה-SQL שב-`netlify/database/migrations/`. אסור לשנות קובץ שכבר רץ: שינוי בסכמה = קובץ חדש עם מספר גבוה יותר.
- **תמונות והקלטות:** Netlify Blobs (המאגר `media`), עד 4MB לקובץ.
- **מחולל המסלולים:** רץ כפונקציית רקע (`ai-job-background`), כי פונקציה רגילה מוגבלת ל-60 שניות. הדף בודק כל כמה שניות אם המסלול מוכן. הקבצים שמצרפים למחולל מוגבלים יחד לכ-4MB.
- **הבינה המלאכותית:** דרך Netlify AI Gateway, שמזריק לפונקציות את המפתח והכתובת של Anthropic בעצמו (השימוש נגבה בקרדיטים של Netlify). אין צורך ב-`ANTHROPIC_API_KEY`; מפתח שמגדירים בעצמכם גובר על ה-Gateway. הפונקציות קוראות משתנים דרך `Netlify.env`, כי ערכי ה-Gateway לא תמיד זמינים ב-`process.env`.
- **הקראה בקול טבעי:** Google Cloud Text-to-Speech בקול עברי (`GOOGLE_TTS_API_KEY`, ואפשר לבחור קול ב-`GOOGLE_TTS_VOICE`, ברירת מחדל `he-IL-Wavenet-A`). ה-AI Gateway לא מציע כרגע מודלי דיבור; `TTS_PROVIDER=gemini` או `openai` ינסו אותם. כל טקסט מוקלט פעם אחת ונשמר (`tts_cache` + Blobs), ואינו נספר במכסת הקבצים של המורה. בלי מפתח – קול המכשיר.
- **משתני סביבה** (Netlify → Project configuration → Environment variables): `ADMIN_EMAILS`, `SITE_OWNER` ו-`CONTACT_EMAIL` (מוצגים בעמודים המשפטיים), ולפי הצורך `RESEND_API_KEY` ו-`MAIL_FROM`, `PAYMENTS_MODE`, `FREE_CREDITS`, `MONTHLY_CREDITS`, `PRICE_LABEL`. אחרי שינוי צריך פריסה מחדש.
- **פריסה:** מתוך התיקייה `learning-paths` עם Netlify CLI (`netlify deploy --prod`), או חיבור הריפו ב-Netlify עם Base directory = `learning-paths`.
- **ניהול מקומי מול האתר החי:** `DATABASE_URL=<connection string מ-Netlify> npm run admin -- show <email>`.

## העלאה לאינטרנט (Render, חלופה)

בשורש הריפו יש קובץ `render.yaml` שמגדיר שרת Node עם דיסק קבוע (מסד הנתונים המקומי נשמר בדיסק) ובדיקת תקינות.

1. נרשמים ל-[render.com](https://render.com) עם חשבון ה-GitHub.
2. **New → Blueprint**, בוחרים את הריפו ולוחצים **Apply**.
3. Render יבקש את הערך של `ANTHROPIC_API_KEY` (בשביל מחולל המסלולים). אפשר להשאיר ריק ולהוסיף אחר כך בלשונית Environment.
4. אחרי כמה דקות המערכת זמינה בכתובת `https://learning-paths.onrender.com` (או דומה). דומיין משלך מחברים ב-Settings → Custom Domains.

הערות:
- הדיסק דורש חבילה בתשלום (Starter). בחבילה החינמית כל הנתונים נמחקים בכל הפעלה מחדש.
- גיבוי: מומלץ להפעיל snapshots לדיסק בהגדרות של Render.
- Render קורא את `render.yaml` מהענף שבוחרים בהגדרות השירות.

## מה יש למורה

- **הרשמה וכניסה** – סיסמאות מוצפנות (scrypt), עוגיית סשן HttpOnly.
- **המסלולים שלי** – יצירת מסלול ריק או ממסלול לדוגמה, שכפול ומחיקה.
- **משימות** – קריאה/הסבר (עם תמונה), סרטון/קישור (יוטיוב מוטמע), שאלה פתוחה, שאלה אמריקאית, רשימת צעדים וזמן עבודה מרוכז עם שעון. לכל משימה זמן משוער וסמל. שינוי סדר בגרירה או בחצים.
- **משחקים ותרגול** – משחק זיכרון (זוגות של מילה/אימוג׳י/תרגיל), תפזורת (טבלה נבנית אוטומטית), התאמה, מתיחת קו (גוררים קו מפריט לבן הזוג שלו), מיון לקבוצות (גוררים פריטים לקופסאות), סידור לפי הסדר, השלמת מילים עם מחסן מילים ומסיחים, נכון/לא נכון, הכתבה (שומעים מילה, בקול המורה או בהקראה, ומקלידים; הבדיקה מתעלמת מניקוד ופיסוק) וכרטיסיות (הופכים כרטיס, "ידעתי" או "עוד פעם", וכרטיס שלא ידעו חוזר). התשובות נבדקות בשרת ולא נשלחות לדפדפן של התלמיד; תשובה שגויה מסמנת בדיוק מה לתקן.
- **עבודה על נייר ולוח ציור** – "צילום עבודה": התלמידים פותרים במחברת ומצלמים את הדף. "לוח ציור": מציירים או כותבים ביד על המסך (צבעים, עובי, מחק, ביטול), אפשר על תמונת רקע של המורה. התמונות מגיעות לטבלת ההתקדמות.
- **סימון על תמונה וסימון מילים** – המורה מעלה תמונה ומסמנת עליה את המקומות הנכונים, והתלמידים לוחצים עליהם. ב"סימון מילים" המורה שמה מילים בסוגריים מרובעים, והתלמידים מסמנים אותן בטקסט (למשל את כל הפעלים). הבדיקה בשרת.
- **ישר מספרים** – התלמידים שמים מספרים, שברים ומספרים מעורבים במקום הנכון על הישר (לחיצה או גרירה, גם באצבע). המורה קובעת התחלה, סוף, קפיצה ואילו מספרים כתובים מתחת לישר.
- **אמצעי המחשה** – לכל משימה אפשר להוסיף ציור מדויק: שבר כעוגה או כפס, או חפצים לספירה (🍎🍎🍎 + 🍎🍎). המחולל מוסיף אותם בעצמו כשהם עוזרים. שברים שכתובים בטקסט (3/4, 1 ו-1/2) מוצגים לתלמידים כשבר אמיתי, והקראה אומרת "שלושה רבעים".
- **תמונות עם AI** – כפתור "🎨 יצירה עם AI" בשדה התמונה של כל משימה, ובמחולל אפשרות "תמונות מאוירות" (עד 3). התמונות בלי טקסט, בסגנון ידידותי לילדים, ועולות 2 קרדיטים כל אחת (`COST_AI_IMAGE`). ב-Netlify הן נוצרות דרך ה-AI Gateway (מודל Gemini); במקום אחר צריך `GEMINI_API_KEY`, ואפשר לבחור מודל ב-`IMAGE_MODEL`.
- **תשובה בקול** – התלמידים מקליטים תשובה במקום לכתוב (מי שאין לו מיקרופון יכול לכתוב), והמורה מקשיבה להקלטה בטבלת ההתקדמות.
- **ניקוד** – מקלדת ניקוד בכל שדה טקסט בעורך (כל התנועות, דגש, שי״ן/שׂי״ן, חולם מלא, שורוק, והסרת ניקוד), וכפתור שמעתיק את הטקסט ופותח את המנקד האוטומטי של דיקטה. בבדיקת תשובות הניקוד לא משנה.
- **מחולל מסלולים (AI)** – כותבים נושא, בוחרים שכבת גיל, מטרות, מספר משימות וסוגי משימות, אפשר לבקש ניקוד מלא ולצרף חומרים (PDF, ‏Word, תמונות, טקסט). המחולל (Claude) בונה מסלול שלם לפי עקרונות של למידה לתלמידי קשב, והוא נשמר כטיוטה לעריכה. כל משימה שחוזרת מהמחולל עוברת את אותה בדיקה כמו משימה שהמורה כתבה.
- **עיצוב** – 8 ערכות מוכנות בלחיצה (קלאסי, חלל, מתחת לים, יער, ממתקים, מחברת, שקיעה, לילה רגוע), ומעבר להן: 12 צבעים ועוד צבע חופשי, מצב יום/לילה, 9 רקעים, 32 סמלים, 5 פונטים, 3 צורות מסלול (דרך מתפתלת, כרטיסים, קו ישר), צורת תחנות (עיגול, ריבוע רך, משושה), סגנון כרטיסים (רך, מסגרת עבה, זכוכית), דמות מלווה שמעודדת את התלמיד/ה, ו-5 סוגי חגיגה. תצוגה חיה ושמירה אוטומטית.
- **אישור מורה** – אפשר לסמן משימה כ"עצירה לאישור המורה". בסוף המשימה התלמיד/ה ממתין/ה, והמורה מקלידה על המסך שלו/ה את קוד האישור של המסלול (4 ספרות, מוסתר במסך המורה עד שמבקשים להציג): "אישור והמשך" או "צריך לתקן". אפשר לאשר גם מרחוק מטבלת ההתקדמות. הקוד לא נשלח לתלמידים, ואחרי 8 ניסיונות שגויים ב-10 דקות הניסיונות נחסמים.
- **התקדמות והפסקות** – פתיחת משימה רק אחרי סיום הקודמת (או חופשי), הפסקה כל X משימות (תנועה מודרכת, נשימות והרגעה, או רעיון ושעון), חגיגה בסיום משימה, כפתור הקראה בקול, "איך אני מרגיש?" ואלבום מדבקות (אפשר לכבות כל אחד).
- **שיתוף** – קוד בן 6 תווים, קישור ישיר וכרטיס להדפסה. המסלול גלוי לתלמידים רק אחרי "פרסום".
- **התקדמות** – טבלת תלמידים × משימות, צפייה בתשובות, בקשות עזרה ("טופל"), רענון אוטומטי.
- **תצוגה מקדימה** – המורה רואה בדיוק את מסך התלמיד, בלי לשמור התקדמות.

## קרדיטים ומנוי

- כל מורה מקבלת **20 קרדיטים חינם** בהרשמה.
- **מסלול חדש** (בנייה עצמאית, ממסלול לדוגמה או שכפול) עולה **קרדיט אחד**. **מסלול מהמחולל** עולה **5 קרדיטים**. עריכה של מסלולים קיימים, תלמידים ומעקב נשארים חינם.
- **מנוי חודשי**: 200 קרדיטים שמתחדשים כל חודש. קרדיטי המנוי נצרכים ראשונים ופגים בסוף החודש. הקרדיטים החינמיים (וקרדיטים שנוספו ידנית) לא פגים.
- אם יצירת מסלול במחולל נכשלת, הקרדיטים חוזרים אוטומטית. בעמוד "הקרדיטים שלי" יש יתרה, מחירון, מצב המנוי והיסטוריית שימוש.

כל המספרים נקבעים במשתני סביבה: `FREE_CREDITS`, `MONTHLY_CREDITS`, `COST_CREATE_PATH`, `COST_AI_GENERATE`, `PRICE_LABEL` (הטקסט שמוצג כמחיר, ברירת מחדל "₪39 לחודש").

**תשלום:** עוד לא מחוברת חברת סליקה.
- `PAYMENTS_MODE=test` – כפתור "הצטרפות למנוי" מפעיל מנוי בלי חיוב, לבדיקה.
- בלי ההגדרה – הכפתור מוחלף בהודעה שהתשלום המקוון עוד לא הופעל.
- בינתיים אפשר לנהל מורות ידנית (למשל בית ספר שמשלם בחשבונית):

```bash
npm run admin -- show dana@school.org
npm run admin -- grant dana@school.org 50        # קרדיטים קבועים
npm run admin -- subscribe dana@school.org 12    # מנוי ל-12 חודשים (עם הקרדיטים של כל החודשים)
npm run admin -- cancel dana@school.org
```

## עוד כלים למורה

- **כיתות** – כיתה עם קוד אחד: התלמידים נכנסים פעם אחת ורואים את כל המסלולים שהוקצו לכיתה, והמורה רואה רשימת תלמידים קבועה עם ההתקדמות בכל מסלול.
- **תמונות והקלטות** – לכל משימה אפשר להוסיף תמונה (תמונות גדולות מוקטנות בדפדפן) ולהקליט את ההוראות בקול. התלמידים שומעים את המורה במקום קול ממוחשב. הקבצים נבדקים לפי התוכן שלהם, עד 5MB לקובץ ו-200MB למורה.
- **ניקוד אוטומטי** – בלחיצה, דרך הנקדן של דיקטה (חינם), או עם Claude (קרדיט אחד).
- **שיפור משימה עם AI** – פשוט יותר, קצר יותר, ניקוד, עוד פריטים, קל או מאתגר יותר, או בקשה חופשית (2 קרדיטים). התוצאה נפתחת לעריכה ונשמרת רק באישור.
- **התאמה אישית** – לכל תלמיד/ה אפשר להסתיר משימות, לקבוע קצב הפסקות משלו/ה והגדרות קריאה (גופן ברור, טקסט גדול, ריווח, ניגודיות גבוהה, מצב שקט, כפתור הקראה), בלי לשנות את המסלול לשאר הכיתה.
- **קישור להורים** – 👪 בטבלת ההתקדמות או בכיתה: קישור סודי שמראה להורים רק את ההתקדמות של הילד שלהם (אילו משימות ומתי, בלי תשובות). אפשר לבטל וליצור חדש.
- **מורה שותפה** – בעמוד הכיתה מוסיפים מורה (שיש לה חשבון) לפי אימייל. היא רואה את התלמידים וההתקדמות ועורכת את מסלולי הכיתה; מחיקה ושיתוף לספרייה נשארים אצל מי שיצרה.
- **תמונת מצב** – בעמוד הכיתה: מה כל תלמיד/ה סיים/ה בכל אחד מ-14 הימים האחרונים, מי לא נכנס/ה שבוע, ומי ביקש/ה עזרה או נתקע/ה.
- **צעדים ראשונים** – מורה חדשה מקבלת מסלול לדוגמה ("מסדרים את התיק") בחינם, סיור קצר ורשימת צעדים שמסתמנים כשהם קורים.
- **דוח להדפסה** – לתלמיד/ה אחד/ת או לכל הכיתה: משימות, תאריכים, זמנים, טעויות, תשובות (כולל צילומים וציורים) ומצב הרוח, ומקום להערות. "שמירה כ-PDF" מהדפדפן.
- **מתי המסלול פתוח** – מועד פתיחה ומועד סגירה. לפני הפתיחה התלמידים רואים מתי ייפתח; אחרי הסגירה רואים את המפה אבל לא ממשיכים.
- **מסלולים מוכנים** – 138 מסלולים מוכנים לפי תוכנית הלימודים, בספרייה תחת "⭐ מסלולים מוכנים": ספר בראשית (מסלול לכל אחד מ-50 הפרקים, כיתות ב׳–ג׳), ספר שמות (פרקים א׳–כ׳), הבנת הנקרא לכל שכבה (א׳–ו׳), שברים עשרוניים, אחוזים וגאומטריה (ד׳–ו׳), כישורי חיים (ארגון, ניהול זמן, התמודדות עם תסכול ועוד), חיבור וחיסור (א׳–ג׳), שברים (ג׳–ו׳), כפל וחילוק, עברית (אותיות דומות, תנועות, חלקי דיבר, יחיד/רבים, שורש, הבנת הנקרא), אנגלית (צבעים, בעלי חיים, מספרים, משפחה) ומדעים (מצבי צבירה, מחזור המים, צמחים, מערכת השמש). מעתיקים ועורכים כמו כל מסלול. התוכן נמצא ב-`content/paths/*.json`; הוראות כתיבה ב-`content/README.md`, ובדיקה ובנייה: `npm run content`.
- **ספריית מסלולים** – משתפים מסלול עם מורים אחרים (עם שכבת גיל ומקצוע), מחפשים, מציצים ומעתיקים עותק לעריכה (קרדיט אחד, כמו מסלול חדש). התלמידים, ההתקדמות וקוד האישור לא משותפים, ומוצג רק השם הפרטי.
- **מצב רוח** – בטבלת ההתקדמות רואים איך כל תלמיד/ה הרגיש/ה בהתחלה ובסוף, ותיבה מסמנת מי בחר/ה היום "מודאג", "עצוב" או "כועס".
- **איפה נתקעים** – ניסיונות שגויים וזמן לכל משימה, ותיבה שמסמנת משימות קשות במיוחד.
- **איפוס סיסמה** – קישור לשעה אחת, לשימוש אחד. אפשר גם ליצור קישור ידנית: `npm run admin -- reset-link <email>`.

## מה יש לתלמיד

- נכנסים עם קוד, שם, דמות וסיסמה סודית של 3 תמונות (בלי אימייל). כדי להמשיך ממכשיר אחר בוחרים את אותן תמונות. ניסיונות ניחוש מוגבלים, והמורה יכולה לאפס סיסמה שנשכחה.
- צלילים קצרים (עם כפתור השתקה), ותגים: צעד ראשון, שלוש משימות, חצי דרך, בול בפעם הראשונה וסיום.
- מפה עם תחנות, "את/ה כאן!", פס התקדמות וכוכבים.
- משימה אחת על המסך, גדולה וברורה, עם זמן משוער, הקראה וכפתור "צריך/ה עזרה".
- חגיגה וכוכב על כל משימה, מסך סיום עם גביע.
- "איך ההרגשה?" בתחילת היום ובסוף המסלול (7 פרצופים, אפשר לדלג).
- מדבקה על כל משימה שמסיימים, ואלבום מדבקות.
- הפסקות מודרכות: קפיצות, מתיחות, "הרובוט אומר", נשימת בלון ועוד, עם אנימציה וספירה (ובהקראה, אם הופעלה).
- מכבד את הגדרת "הפחתת תנועה" של המכשיר.
- כפתור Aa: גופן ברור, טקסט גדול, ריווח, ניגודיות גבוהה, מצב שקט והקראה בקול טבעי (או בקול המכשיר).

## עמודים משפטיים

מדיניות פרטיות, תנאי שימוש והצהרת נגישות (`public/js/legal.js`, בתחתית כל עמוד), והסכמה לתנאים בהרשמה (נשמר `terms_accepted_at`). אלה טיוטות: יש להעביר לבדיקת עורך/ת דין לפני שימוש מסחרי.

## הערות

- הניקוד של דיקטה משתמש בשירות הציבורי שלהם. את תנאי השימוש (במיוחד לשימוש מסחרי) צריך לבדוק מול דיקטה לפני עלייה לאוויר.
- המחולל שולח את הנושא והקבצים ל-Anthropic. אין לצרף מידע אישי על תלמידים. כל יצירת מסלול עולה כמה סנטים עד עשרות סנטים בחשבון ה-API, לפי אורך הקבצים. יש מגבלה של 20 מסלולים לשעה למורה.
- הפונטים נטענים מ-Google Fonts (Rubik, Varela Round, Playpen Sans Hebrew, Secular One). בלי אינטרנט המערכת עובדת עם פונט המערכת.
